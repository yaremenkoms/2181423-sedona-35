# Моушен-ролик по озвучке

Эталон — `marketing/launch/flybrain/` («Мозг мухи», 30.09.2026, 9:16, 62,8 с). Новый ролик = копия служебных скриптов оттуда + новые сцены. Весь цикл ≈ 1–1,5 ч, из них полный рендер ≈ 8 мин на 60 с.

Другие образцы стиля в `marketing/launch/`: `reels/` (лонч СлушАЙ, плотные SFX), `student/` (яркий необрутализм, мемные звуки), `cartoon/` (рисованная комната, «дышащая» обводка), `launch.html` (твиттерный 16:9).

## Вход
- Аудио (mp3/wav) и **текст озвучки от пользователя** — текст главный источник для субтитров.
- Формат по умолчанию 1080×1920, 30 fps. Голос можно ускорить ×1.1–1.15, если пользователь разрешил.

## Шаги

1. **Папка.**
   ```bash
   cd marketing/launch && mkdir <slug> && cd <slug>
   cp ../flybrain/{edit.py,words.py,render.js,mix_lib.py,sheet.sh} .
   cp ../flybrain/mix.py . && cp ../flybrain/flybrain.html <slug>.html
   sed -i '' 's/flybrain.html/<slug>.html/' render.js
   cp "<аудио>" vo.mp3
   ```
2. **Тайм-коды.** `python3 words.py` → `vo_words.json` (whisper-1, ключ `GPT_API_KEY` из `env_server.txt` в корне; ключ не печатать).
3. **Паузы и темп.** В `edit.py` перед запуском: `TEMPO`; `KEEP` — очистить (там паузы прошлого аудио) и вписать свои драматические паузы (старт паузы из silencedetect → сколько оставить); `FIX` — замены под новый текст (ё, латиница, числа); `PAIR` — очистить (замены по соседнему слову, для падежей). `python3 edit.py` → `vo_fast.wav`, `words.json` (время уже на новой шкале).
4. **Субтитры = текст пользователя.** Сверить `words.json` с текстом: whisper теряет запятые/двоеточия, путает падежи. Правится 4-й элемент слова (display). Потом:
   ```bash
   python3 - <<'EOF'
   import json; w=json.load(open('words.json'))
   tl={'fps':30,'end':round(w['dur']+2.6,1),'vo_dur':w['dur'],'words':w['words']}
   json.dump(tl,open('timeline.json','w'),ensure_ascii=False)
   open('timeline.js','w').write('window.TL='+json.dumps(tl,ensure_ascii=False)+';\n')
   EOF
   ```
5. **Сценарий.** 10–18 сцен по 2–5 с, одна мысль и один визуальный приём на сцену. Каждое появление привязано к слову: `W('слово', n)` — n-е вхождение нормализованного слова whisper (нижний регистр, без «ё», цифры цифрами).
6. **Сцены в HTML** (устройство как в `flybrain.html`):
   - `renderAt(t)` детерминирован — любой кадр рендерится независимо.
   - `K` — словарь моментов из `W()`; `SCN` — таблица `[id, t0, t1, вход, выход]`, переходы `cut | up | left | zoom | zoomIn | fade`; каждая сцена — `div.scene` + `U.<id>(t)`.
   - Общие слои: `GLOW` (цвет свечения по сцене), `SHAKE`, `FLASH`, `CHAP` (главы + полоса прогресса), субтитры собираются сами из timeline. Таблицы `LIGHT` (где `.light` на `#stage` — светлые сцены) и `NOCAP` (где скрыть субтитры) — переписать под свои сцены вместе с остальными.
   - Хелперы: `charsIn` (буквы с blur и пружиной), `spr` (пружина), `KF` (ключевые кадры), `tf`, `split`/`words`.
   - Готовые блоки для переиспользования: `flySVG`/`flutter` (муха), `BR` + `brainState` (3D-облако точек), `DOOM.render` (рейкастер), `drawCandles` (биржевой график), `makeFeed`/`feedAnim` (телефон с лентой), `EM` (срезы микроскопа), `drawRaster` (активность нейронов), `MCM` (изометрия блоков), `cube`/`drawSugar` (падающие 3D-кубы), `cardPos` (карточки на «тросах»).
   - Зона Y 1545–1700 — только субтитры; шапка 170–230 — глава и прогресс.
7. **Проверка кадров — обязательно.**
   ```bash
   rm -rf stills && node render.js stills 0.5,1.6,3.3,...   # кадр на каждую сцену + середины переходов; старые кадры иначе попадут в листы
   ./sheet.sh                               # листы sheet_N.jpg по 12 кадров
   ```
   Открыть листы через Read и искать: текст перекрыт графикой, пустые кадры, выход за края, контент в зоне субтитров, нечитаемость в светлых сценах. Править → повторить.
8. **Полный рендер в фоне:** `node render.js video` → `out/video.mp4`. Пока идёт — микс.
9. **Звук:** `python3 mix.py` → `out/mix.wav`. Музыка D-минор 120 BPM, сетка привязана к дропу; SFX расставлены по словам. Скрипт печатает баланс по 4-секундным окнам: **голос на 5–6 дБ громче фона**, иначе снизить общие `.34`/`.42` или гейн конкретных звуков. Итог loudnorm −14 LUFS.
10. **Склейка:**
    ```bash
    ffmpeg -v error -y -i out/video.mp4 -i out/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart out/<slug>_9x16.mp4
    ```
11. **Точечные правки без полного рендера:** `node render.js video FROM TO seg.mp4`, затем вклейка (F0 = FROM×30, F1 = TO×30):
    ```bash
    ffmpeg -v error -y -i out/video.mp4 -i out/seg.mp4 -filter_complex "[0:v]split[v0][v1];[v0]trim=end_frame=F0,setpts=PTS-STARTPTS[a];[1:v]setpts=PTS-STARTPTS[b];[v1]trim=start_frame=F1,setpts=PTS-STARTPTS[c];[a][b][c]concat=n=3:v=1[v]" -map "[v]" -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p out/video2.mp4 && mv out/video2.mp4 out/video.mp4
    ```
    и снова шаг 10.
12. **Отдать** файл через SendUserFile, дописать в память (`slushai-launch-video.md`) одну строку: что за ролик, где лежит, новые грабли.

## Стиль
- Тёмный фон `#07080B`, точечная сетка, цветное свечение по сцене; 1–2 акцента на сцену из палитры lime `#C8FF3E`, cy `#46E0FF`, vio `#A58BFF`, pink `#FF4FB0`, gold `#FFC53D`, hot `#FF4A2B`.
- Шрифты: Inter Tight 800–900 — заголовки и числа; JetBrains Mono — подписи и данные; Playfair Display italic — «возвышенные» слова; Press Start 2P — игры.
- Буквы появляются с blur, подъёмом и пружиной; числа — счётчиками; интерфейсы (карточки, телефоны, терминалы, графики, игры) рисуются кодом, не картинками.
- Ключевое слово озвучки = главное слово на экране. 1–2 светлые сцены как контраст перед важной мыслью. Финал обращён к зрителю.
- Звук: свуш/удар на каждой склейке, свой звук на каждое появление, тейп-стоп перед драматической фразой, дроп после паузы.

## Картинки
Если сцене нужен фон, реквизит или фактура, которую долго рисовать кодом, — генерировать через gpt-image-2.5-flare:
```bash
mkdir -p img && python3 ../gen/gen.py img/<имя> "<промпт>" [1024x1024|1024x1536|1536x1024] [low|medium|high] [auto|transparent]
```
- Ключ скрипт берёт сам из `env_server.txt`. Другая модель — env `IMG_MODEL` (на ключе есть ещё gpt-image-2.5-sunburst, gpt-image-2, 1.5, 1-mini).
- Начинать с `low` (≈300 токенов на 1024²), `medium`/`high` — только для крупных планов. Для вырезок — `transparent`: 2.5 даёт честную альфу, mini — нет.
- Героев, интерфейсы, числа и любой текст — кодом: генерация не держит одинаковый вид от кадра к кадру, надписи — только в DOM.
- В HTML — `<img src="img/<имя>.png">`, оживлять трансформами, параллаксом, дрожанием. Ролик целиком на генерации — `hr/` (коллаж из ~14 вырезок).

## Грабли
- Папка ролика — строго `marketing/launch/<slug>/` в slushai: `words.py` и `gen.py` ищут `env_server.txt` на 3 уровня выше, `render.js` берёт playwright из `marketing/launch/node_modules`.
- Google Fonts грузятся из сети — без интернета кадры уйдут в системные шрифты. Эмодзи — Apple Color Emoji (только Mac).
- `mix.py` делает `globals().update(K)` — не называть свои переменные так же, как моменты сцен (сетка музыки — `GOFF`, не `G0`).
- zsh: `$n:l` — модификатор, писать `${n}`. Нет `timeout`, PIL и scipy — листы кадров через `sheet.sh` (ffmpeg xstack).
- Canvas-мозг рисуется на общем `#cv` под сценами: при уходе сцены смещать его вручную в `brainState`.
- Передний слой частиц (canvas поверх) не должен закрывать заголовки — заголовок ставить в DOM после него.
