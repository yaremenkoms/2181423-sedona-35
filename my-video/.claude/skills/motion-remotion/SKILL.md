# Моушен-ролик по озвучке (Remotion)

Перенос подхода скилла `motion-video` в этот Remotion-проект. Эталон — `src/motion/videos/send-homework.tsx`
(«Как отправить работу на проверку», 9:16, 49 с). Новый ролик = новый файл сценария + папка материалов.

Устройство:
- `src/motion/core.tsx` — шрифты, палитра `P`, `makeW` (время слова), `useT` (абсолютное время в сцене),
  `useSpr`, `CharsIn` (буквы с blur и пружиной), `Pop`, `useCount`;
- `src/motion/Stage.tsx` — `MotionVideo`: фон с точечной сеткой, свечение сцены, переходы, вспышка, встряска,
  главы с прогрессом, субтитры по словам, звук (голос + музыка + SFX, свуш на каждой склейке — сам);
- `src/motion/blocks.tsx` — приёмы: `Kicker`, `Title` (строки по словам, курсив Playfair), `Mono`, `Counter`,
  `Phone` + `AppCard` + `AppButton` (нажатие с кольцом), `Chips`, `Paper`, `PageStack`, `Camera` (видоискатель
  со вспышкой), `PhotoGrid`, `BigCheck`, `Confetti`, `Zone` (контентная зона);
- `public/motion/<slug>/` — `voice.mp3`, `text.txt`, `words.json`, `music.wav`; `public/motion/sfx/` — эффекты.

## Вход

- Аудио (mp3/wav) и **текст озвучки от пользователя** — текст главный источник субтитров.
- Формат по умолчанию 1080×1920, 30 fps (16:9 — `width: 1920, height: 1080`, зоны в `Zone` поправить).
- Темп голоса не меняем без разрешения пользователя.

## Шаги

1. **Папка:** `public/motion/<slug>/`, туда `voice.mp3` и `text.txt` (текст пользователя как есть).
2. **Слова:**
   ```bash
   M=$(bash .claude/skills/motion-remotion/scripts/setup_asr.sh)
   python3 -I .claude/skills/motion-remotion/scripts/words.py $M public/motion/<slug>/voice.mp3 public/motion/<slug>/text.txt > public/motion/<slug>/words.json
   ```
   Модель zipformer RU (GitHub Releases, ~320 МБ, без ключей) даёт время, текст берётся из `text.txt`.
   Смотри `matched` (должно быть ≥ 90%) и проверь глазами слова после пауз. Числа цифрами («5», «10»)
   модель слышит словами — они получают время интерполяцией, это нормально.
3. **Сценарий** — 10–16 сцен по 2–5 с, одна мысль и один визуальный приём на сцену. Все моменты — через
   `W('слово', n)` (n-е вхождение; нижний регистр, без «ё» и знаков; «5» → `W("5")`). Границы сцен — на
   словах, начинающих новую мысль. 1–2 светлые сцены (`light: true`) как контраст перед важной мыслью.
   Финал обращён к зрителю. Главы (`chapters`) — 3–5 коротких слов.
4. **Сцены:** `src/motion/videos/<slug>.tsx` по образцу эталона: `MotionConfig` + обёртка-компонент
   `export const X: React.FC = () => <MotionVideo cfg={...} />` (сцены содержат JSX — **их нельзя передавать
   через `defaultProps`**, Remotion сериализует пропсы → React error #31).
   Зарегистрируй в `src/Root.tsx` в `<Folder name="MOTION">`, `durationInFrames={Math.ceil(motionDuration(cfg) * 30)}`.
   Новый приём, которого нет в `blocks.tsx`, — добавь туда как переиспользуемый компонент, тайминги — через `useT`/`useSpr`.
5. **Музыка:** `python3 -I .claude/skills/motion-remotion/scripts/synth.py music public/motion/<slug>/music.wav <длина_с> <дроп_с>`
   (ре минор, 120 BPM, сетка от дропа; дроп — первый шаг/главная мысль; длина = озвучка + `endPad`).
   Эффекты уже лежат в `public/motion/sfx/` (пересоздать: `synth.py sfx public/motion/sfx`).
   SFX в `cfg.sfx`: `hit` — на важном/числе, `pop` — появления, `tick` — счётчики и списки, `click` — нажатия,
   `riser` — за 2 с до дропа, `stop` — тейп-стоп перед драматической фразой. Встряска — `cfg.shake`.
6. **Баланс:** `python3 -I .claude/skills/motion-remotion/scripts/balance.py voice.mp3 music.wav <music.gain>` —
   голос должен быть на 5+ дБ громче музыки в каждом окне с речью; иначе уменьши `music.gain`.
7. **Проверка кадров — обязательно.** Кадр на каждую сцену (середина) + середины переходов:
   ```bash
   npx remotion still motion-<slug> /tmp/st/NN.png --frame=<сек*30> --browser-executable=$BX
   ffmpeg -i /tmp/st/%02d.png -vf "scale=360:-1,tile=7x2" /tmp/st/sheet.png
   ```
   Открой лист через Read. Ищи: текст вылезает за края, перекрыт графикой, контент в зоне субтитров
   (Y 1545–1700) или шапки (170–230), нечитаемость в светлых сценах, пустые кадры. Править → повторить.
8. **Рендер в фоне:** `npx remotion render motion-<slug> out/<slug>-raw.mp4 --browser-executable=$BX`.
9. **Громкость:** `bash .claude/skills/motion-remotion/scripts/finish.sh out/<slug>-raw.mp4 out/<slug>_9x16.mp4` → −14 LUFS.
10. **Отдать** через SendUserFile и коротко перечислить сцены и что стоит проверить.

`BX=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell` — в облачном контейнере Remotion
не может скачать свой браузер.

## Стиль

- Тёмный фон `#07080B`, точечная сетка, цветное свечение по сцене (`glow`); 1–2 акцента на сцену из палитры
  lime `#C8FF3E`, cy `#46E0FF`, vio `#A58BFF`, pink `#FF4FB0`, gold `#FFC53D`, hot `#FF4A2B`.
- Шрифты (локально, из npm @fontsource): Inter Tight 800–900 — заголовки и числа; JetBrains Mono — подписи и
  данные; Playfair Display italic — «возвышенные» слова.
- Буквы — с blur, подъёмом и пружиной; числа — счётчиками; интерфейсы (кнопки, карточки, телефоны) — кодом.
- Ключевое слово озвучки = главное слово на экране. Субтитры — ровно текст пользователя, текущее слово
  подсвечено цветом сцены.
- Звук: свуш на каждой склейке (автоматически), свой звук на каждое появление, удар + встряска на главном.

## Чего здесь нет (в отличие от motion-video)

- **Генерации картинок** (gpt-image) — сети к OpenAI нет. Всё рисуется кодом; если нужна фактура или фото —
  попроси у пользователя файлы и положи в `public/motion/<slug>/`.
- **Ускорения голоса и драматических пауз** (`edit.py`) — не делаем без отдельной просьбы; если просят —
  `ffmpeg -af atempo=1.1` до шага 2.

## Грабли

- Внутри сцены `useCurrentFrame()` локальный — для абсолютного времени только `useT()`/`useSpr()`.
- Если исходное аудио уже содержит музыку (например, взято из готового ролика) — свою музыку не добавляй или
  сделай `gain` ≤ 0.1, иначе каша.
- Слишком длинная строка `Title` вылезает за край: при 1080 px ширины держи ≤ 12 символов на 128 px.
- Пропуски `words.py`: первое слово после паузы прижимается к концу паузы — если подсветка опаздывает, проверь
  `words.json` и поправь `start` вручную.
